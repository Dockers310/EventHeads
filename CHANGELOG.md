# EventHeads 3.5.6

Текущая версия плагина.

## 3.5.6
- Роли: имя встроенной роли нельзя занять кастомной; права новой роли и точечные права выдаются только из тех, что есть у выдающего; менять можно только игрока, чья текущая роль ниже своей; `access.allow-admin-to-grant-admin: false` действует и на ADMIN.
- Экономика: одна выплата идёт по одному каналу. В режиме AUTO первым используется Vault; после отправленной, но не подтверждённой команды другие каналы не пробуются (раньше награда могла выдаться дважды).
- Игроку пишется, сколько начислено за предмет (`collect`) и сколько списано за штраф или отрицательную награду (`economy-spent`, с балансом). Раньше это сообщение писала команда CMI; транзакция Vault проходит молча. Отключается `economy.notify-player: false`.
- `/eh spawn test` требует прав `test` и `spawn`; тестовый предмет собирается без награды и статистики.
- Награды и штрафы ограничены `economy.reward-limit`; большой разброс награды больше не вызывает ошибку при сборе. Штраф за невыполненное условие снимается не чаще раза в `economy.fail-penalty-cooldown-seconds`.
- Anti-ESP: закопанные приманки создаются только целиком в земле; срабатывания по наземным приманкам учитываются в пределах `security.anti-esp-report-surface-window-seconds`.
- WorldGuard и WorldEdit: интеграции переведены на актуальный API (WorldGuard 7, WorldEdit 7); если API не распознан, об этом сообщается в консоли. Место спавна в регионе WorldGuard выбирается до запуска задачи, чтобы на Folia она выполнялась в нужном регионе.
- `/eh reload` больше не стирает несохранённую статистику, журнал и активные экземпляры.
- Выключение сервера: плагин не ставит задачи из `onDisable`.
- Лимит частиц анимации за тик (`animation.max-particles-per-tick`), привязка права `eventheads.use` больше не накапливается при каждом входе, права в меню проверяются при каждом клике и при применении введённого значения.
- Супер-администратора можно задать по UUID (`access.super-admin-uuids`).
- Плагин загружается и без PacketEvents (он объявлен как softdepend): раньше сервер без PacketEvents отклонял плагин с `NoClassDefFoundError`.

## 3.5.5
- Восстановлена полная локализация GUI и чата после изменений в ролях.
- Переведены новые настройки лимита точек, радиуса и центра постановки для всех поддерживаемых языков.
- Проверены словари локализации: дубликаты ключей и непереведённые русские фрагменты устранены.
- Игровая механика 3.5.4 не изменялась.

## 3.5.4
- Обычный игрок может собирать EventHead ЛКМ и ПКМ.

## 3.5.3
- Лимит точек, радиус и центр постановки реально учитываются по назначенной роли.
- Ограничения собственной роли нельзя изменять из меню сотрудника.
- «Настройки моей роли» являются информационным предметом и ничего не открывают.

## 3.5.2
- Настройки лимита точек, радиуса и центра добавлены в существующую систему ролей.
- Ограничения роли сохраняются в `access.yml`.

## 3.5.0
- Добавлена поддержка Paper и Folia.
- Анимация сбора сохранена по рабочей схеме EventHeads с ArmorStand и существующей системой частиц.
- Планирование задач переведено на Folia-совместимые Global/Region/Entity Scheduler.
- Исправлено восстановление `collected=true` и очистка старых зависших экземпляров.
- Диагностика показывает фактическое ядро Paper или Folia.
- Anti-ESP для административного состава по умолчанию использует `hide`.

## 3.4.9
- Начат перенос плагина на Paper/Folia.
- Добавлена работа через scheduler-модель Folia.
- Добавлена очистка старого runtime и восстановление состояния сработавших событий.
